# 🚗 우왕카 — 충북대 주변 렌터카 예약 시스템 (C)

> 충북대학교 지능로봇공학과 **오픈소스 기초 프로젝트** · 2024.05

충북대 주변에는 여러 렌터카 업체가 학교 문(정문·중문·후문·서문) 근처에 흩어져 있어 **위치와 가격을 한눈에 비교하기 어렵다**는 점에서 출발했습니다.
업체별 차량 정보를 한 화면에 모아 **게이트 → 주차 위치 → 차종 → 가격** 조건으로 걸러 보고 예약하는 Windows 콘솔 프로그램입니다.

| 항목 | 내용 |
|---|---|
| 언어 | C (MSVC, Visual Studio) |
| API | Windows Console API (커서 위치·색상·화면 버퍼), `conio.h`의 `_getch()` |
| 핵심 | 포인터와 동적 할당(`malloc` · `realloc` · `free`), 비트 연산 필터, 파일 입출력 |
| 데이터 | 게이트 4곳 · 주차 위치 9곳 · 차량 25대 |

---

## 주요 기능

### 1. 로그인 · 회원가입
- 이름, 아이디, 비밀번호, 운전면허 번호(10자리), 주민등록번호(생년월일 + 뒤 1자리), 학번(10자리)을 형식에 맞게 입력받습니다.
  - 입력 함수에 필터를 둬 숫자 칸은 숫자만, 아이디·비밀번호 칸은 한글을 막습니다.
  - 형식이 틀리거나 이미 있는 아이디면 빨간 글씨로 안내합니다.
- 가입 정보는 `userdata.txt`에 **이어쓰기(`a`)**로 추가하고 맨 위 회원 수는 **읽기+쓰기(`r+`)**로 덮어써, 프로그램을 다시 켜도 같은 계정으로 로그인할 수 있습니다.
- 회원가입 화면에서 `< 뒤로`로 로그인 화면에 돌아갈 수 있습니다.

### 2. 차량 목록과 필터
화면 예시:
```
================== [필터] ==================
 - 게이트   정문  중문  후문  서문
 - 위치     롯데렌탈 청주지점(B)  충북대학교 중문(그레이스빌) ...
 - 차종     더 뉴 k3 1.6  올 뉴 아반떼  XM3 ...
 - 가격     Price per hour  최소 ~ 최대 / Price per km  최소 ~ 최대
[필터 초기화]
============== [차량 리스트] ==============
    더 뉴 k3 1.6 | (11250원/h / 210원/km)
    ...
```
- 게이트·위치·차종은 이 순서로 우선순위를 두고 여러 개를 동시에 고를 수 있으며, 시간당·km당 요금은 최소~최대 범위로 거릅니다.
- 차량마다 조건 일치 여부를 **정수 하나의 비트**로 기록(게이트 · 위치 · 차종 · 시간당 요금 · km당 요금)한 뒤, 비트를 비교해 목록에 보여줄지 정합니다.
- 적용한 조건은 초록색, 커서가 올라간 줄은 흰색, 둘이 겹치면 회색으로 표시합니다. 조건에 맞는 차가 없으면 빈 목록을, `[필터 초기화]`를 누르면 전체 목록을 다시 보여줍니다.

### 3. 예약 · 취소
- 목록에서 차를 고르면 예약 완료(파란 창), 이미 예약한 차를 다시 고르면 예약 취소(빨간 창)가 뜹니다.
- 예약한 차는 목록에서 파란색으로 표시되고, 예약 목록은 `realloc`으로 크기를 바꾸는 동적 배열로 관리합니다.
- `[사용자 정보 보기]`에서 가입 정보와 예약한 차량 목록을 확인합니다.

## 동작 구조

```
main()
 ├─ get_car_data_list()    "lental car data.txt" → CarData 동적 배열
 ├─ get_user_data_list()   "userdata.txt"        → UserData 동적 배열
 ├─ user_login() / user_join() → save_user_data()
 ├─ 차종·게이트·위치 이름 중복 제거 → 필터 항목 목록 생성
 └─ 메인 루프: 필터 화면 출력 → 방향키 입력 → 필터 갱신 / 예약 토글 / 사용자 정보
```

```c
typedef struct {
    int   id;        // 차량 고유 번호
    char* name;      // 차종
    char* gateTag;   // 가까운 학교 문 (정문/중문/후문/서문)
    char* location;  // 주차 위치
    int   PPH;       // 시간당 요금 (price per hour)
    int   PPK;       // km당 요금 (price per km)
} CarData;

typedef struct {
    char* name;  char* license;  char* RRN;   // 이름, 운전면허 번호, 주민등록번호
    char* studentId;  char* id;  char* password;
} UserData;
```
문자열은 읽어 온 길이에 맞춰 동적으로 할당합니다.

## 빌드 및 실행 (Windows)

1. Visual Studio에서 빈 프로젝트를 만들고 `rental_car_11.c`를 추가합니다. (Windows 10에서는 `rental_car_10.c`)
2. `lental car data.txt`, `userdata.txt`를 프로젝트 폴더에 둡니다. (두 파일은 EUC-KR 인코딩)
3. `Ctrl + F5`로 실행합니다.

```cmd
:: 명령줄 빌드 (Developer Command Prompt)
cl rental_car_11.c
rental_car_11.exe
```

## 어려웠던 점

| 문제 | 해결 |
|---|---|
| Windows 10에서 만든 화면이 Windows 11 CMD에서 깨짐 — 커서가 창 높이를 넘어가면 이동이 무시돼 줄이 옆으로 밀리고, 다시 그릴 때 아래로 계속 쌓임 | 콘솔 화면 버퍼 높이를 기준으로 페이지를 계산해, 스크롤 없이 보이는 높이 안에서만 출력하도록 `gotoxy()`를 수정 (`rental_car_11.c`) |
| 회원 데이터를 파일에 저장할 때 기존 내용이 지워지거나 회원 수를 갱신하기 어려움 | `w`(새로 쓰기), `a`(이어쓰기), `r+`(읽기+덮어쓰기)의 차이를 정리해, 회원 정보는 이어쓰고 회원 수만 `r+`로 덮어씀 |

## 아쉬운 점 (구현하지 못한 것)

- 차량 사진 출력
